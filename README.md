# Система диагностики диабета

## Описание проекта

Проект представляет собой систему машинного обучения для диагностики диабета у пациентов на основе медицинских показателей.

Используется набор данных **Pima Indians Diabetes Database**, содержащий информацию о пациентах и наличии/отсутствии диабета.

Проект включает:

- обучение модели машинного обучения;
- анализ качества модели;
- визуализацию ошибок;
- веб-интерфейс на Gradio;
- автоматические тесты.

---

## Цель проекта

Разработать модель классификации, способную определять вероятность диабета по медицинским показателям пациента.

---

## Источник данных

Используемый датасет:

**Pima Indians Diabetes Database**

Источник: OpenML / UCI Machine Learning Repository.

---

## Используемые признаки

Модель использует следующие параметры пациента:

- количество беременностей;
- уровень глюкозы;
- артериальное давление;
- толщина кожной складки;
- уровень инсулина;
- BMI (индекс массы тела);
- наследственная предрасположенность к диабету;
- возраст.

---

## Используемые модели

В проекте сравниваются две модели:

1. Простая собственная модель на основе порога глюкозы.
2. Random Forest Classifier.

Лучшая модель выбирается на основе метрики F1-score.
