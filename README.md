# Кластеризация стран по социально-экономическим показателям

## Описание проекта

Проект представляет собой систему машинного обучения для кластеризации стран на основе социально-экономических показателей.

Используется датасет **World Happiness Report 2023**, содержащий показатели качества жизни, экономики, социальной поддержки, свободы выбора и других факторов, влияющих на благополучие населения.

Проект включает:

- подготовку и обработку данных;
- обучение и сравнение моделей кластеризации;
- анализ качества моделей;
- визуализацию кластеров;
- веб-интерфейс для взаимодействия с моделью;
- автоматические тесты.

---

## Цель проекта

Разработать модель машинного обучения, способную группировать страны по схожим социально-экономическим характеристикам.

## Используемые признаки

Модель использует следующие социально-экономические показатели:

- Logged GDP per capita;
- Social support;
- Healthy life expectancy;
- Freedom to make life choices;
- Generosity;
- Perceptions of corruption.

Данные признаки используются для определения схожести стран и их последующей кластеризации.

---

## Используемые модели

В проекте реализовано сравнение двух подходов:

### 1. Простая собственная модель

Самописная модель, использующая правило на основе уровня экономики (GDP) и продолжительности жизни для распределения стран по группам.

### 2. KMeans

Алгоритм кластеризации из библиотеки Scikit-learn, автоматически разделяющий страны на группы со схожими характеристиками.

Выбор лучшей модели выполняется на основе качества кластеризации.

---

## Метрики качества

Для оценки моделей используются:

### Silhouette Score

Показывает, насколько хорошо разделены кластеры.

Чем выше значение, тем качественнее разделение.

### Davies-Bouldin Score

Оценивает компактность кластеров и расстояние между ними.

Чем ниже значение, тем лучше.
