# Система диагностики диабета

## Описание проекта

Проект представляет собой систему машинного обучения для диагностики диабета у пациентов на основе медицинских показателей.

Используется датасет **Pima Indians Diabetes Database**, содержащий медицинские параметры пациентов и информацию о наличии или отсутствии диабета.

Проект включает:

- подготовку и обработку данных;
- обучение и сравнение моделей классификации;
- анализ качества модели;
- визуализацию ошибок;
- веб-интерфейс для взаимодействия с моделью;
- автоматические тесты.

---

## Цель проекта

Разработать модель машинного обучения, способную определять вероятность диабета на основе медицинских показателей пациента.

## Используемые признаки

Модель использует следующие параметры пациента:

- количество беременностей;
- уровень глюкозы;
- артериальное давление;
- толщина кожной складки;
- уровень инсулина;
- BMI (индекс массы тела);
- наследственная предрасположенность к диабету;
- возраст.

---

## Используемые модели

В проекте реализовано сравнение двух подходов:

### 1. Простая собственная модель

Модель использует простое правило на основе уровня глюкозы (пороговое значение).

### 2. Random Forest Classifier

Более сложный алгоритм машинного обучения из библиотеки Scikit-learn.

Выбор лучшей модели выполняется по качеству метрик классификации.

## Установка проекта

Клонировать репозиторий:

```bash
git clone <url_репозитория>
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

---

## Обучение модели

Перед запуском веб-интерфейса необходимо обучить модель:

```bash
python train.py
```

После выполнения будут созданы:

```text
model/saved_model.pkl
model/scaler.pkl
results/confusion_matrix.png
```

---

## Запуск веб-интерфейса

Запуск приложения:

```bash
python app.py
```

После запуска открыть в браузере:

```text
http://127.0.0.1:7860
```

В интерфейсе необходимо ввести медицинские показатели пациента, после чего модель оценит вероятность наличия диабета.

## Автоматическое тестирование

Для проверки корректности работы проекта используются автоматические тесты.

Запуск тестов:

```bash
pytest
```

Пример успешного результата:

```text
3 passed
```

Тесты проверяют:

1. Корректную работу функции предсказания.
2. Формат возвращаемого результата.
3. Возможность создания веб-интерфейса без ошибок.
